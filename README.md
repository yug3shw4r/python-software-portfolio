# Core Software Projects

A collection of academic and practical software development projects focusing on Machine Learning, Natural Language Processing, and Backend System Architecture. 

## 1. Modular Ride-Booking System
A backend engine simulating the core workflow of a ride-hailing application. 
* **Tech Stack:** Python, SQLite, JSON APIs
* **Features:** In-memory SQL database management for Users, Drivers, and Rides; API payload parsing; dynamic ride assignment logic.

## 2. Student Performance Predictor
A machine learning model built to predict academic outcomes based on structured student data.
* **Tech Stack:** Python, Pandas, Scikit-Learn
* **Features:** Data preprocessing, train/test splitting, linear regression modeling, and Mean Absolute Error (MAE) evaluation.

## 3. AI-Based FAQ Assistant
An NLP-powered text processing application that matches user queries to an internal knowledge base.
* **Tech Stack:** Python, Scikit-Learn (TF-IDF, Cosine Similarity)
* **Features:** Vectorization of text data, similarity-based matching, and dynamic response generation.
